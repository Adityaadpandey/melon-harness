---
title: "Windows"
description: "How zerd runs on Windows 10 and 11, and what differs from macOS and Linux."
---

zerd runs natively on Windows 10/11 (x64). Install [Git for Windows](https://git-scm.com/download/win) first.

## The shell

Shell commands run in Git Bash, so the bash a model writes for macOS and Linux works unchanged. Without Git for Windows, zerd falls back to PowerShell.

## What differs

The OS sandbox is macOS only. On Windows you have the confined file tools and the shell path scan.

That scan only looks for Unix-style paths. A command that names a `C:\...` path outside the project slips past it, while `/etc/passwd` would be caught.

<Callout type="warn">
Read shell commands that touch `C:\...` paths before approving them. The path scan will not flag them.
</Callout>

## Other notes

- Use Windows Terminal. `ZERD_PLAIN=1` gives the classic scrolling layout.
- CI builds and tests on Windows, but the Windows test run is reported, not required yet.
