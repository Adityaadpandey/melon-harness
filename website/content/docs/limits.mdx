## Known gaps

- The OS sandbox is macOS only. Linux and Windows get the confined tools and the shell path check, but not the kernel layer.
- There is no image input (pasting a screenshot) and no IDE extension.
- Signature checks cover Python and JS/TS only. Python outlines come from an indentation-based reader rather than a real parser. Diagnostics come from `tsserver` for TypeScript and quick checkers elsewhere, and there is no general language server.
- Token counts are estimated (bytes divided by 4), not counted exactly.
- The benchmarks are small: one project and one run each in round 2, and 11 tasks in round 1, measured on the earlier Python version. They show where verification pays off and do not rank anything. The defaults are tuned on one real repo, so they are only measured there.

## Tests

```bash
cargo test        # about 550 tests, no network, no real model, around 20 seconds
```

Every test uses a scripted model (`src/tests/fakes.rs`) and a throwaway data folder, so no API credits are spent and nothing touches your real sessions or keys. The codebase is about 28k lines of Rust plus 8.6k lines of tests.
