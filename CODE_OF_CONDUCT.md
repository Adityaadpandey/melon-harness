# Code of Conduct

We want zerd to be a place where people can ask questions, report problems and send code without being treated badly.

**Do:** be kind and patient, assume good intent, give feedback on the work and not the person, and accept feedback the same way.

**Don't:** harass, insult or demean anyone, post other people's private information, or keep pushing after someone has said stop.

This applies in issues, pull requests, discussions and any space where you speak for the project.

## Enforcement

Maintainers may edit or remove comments, close threads, and block people who break these rules. To report a problem, use
GitHub's "Report content" on the comment, or open a private security advisory on the repo and say it is a conduct report.

This text is a short version in the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
